# 0.1. Welcome!

Welcome to the manual for the NHM **Variant Calling** course — a 2-day, hands-on
introduction to going from raw sequencing reads to a filtered set of SNPs, and on to
the biological questions those SNPs can answer.

!!! abstract "Learning objectives"
    Over the two days you will be able to:

    - Describe the variant-calling workflow end to end, from reads to insights
    - Take raw reads through QC, alignment and variant calling to a raw VCF
    - Filter a raw VCF into a trustworthy SNP set and explore it
    - Run a downstream analysis (population genomics or phylogenetics) on the result

## Schedule at a glance

| Day | Theme | Sessions |
| --- | --- | --- |
| **Day 1** | From reads to SNPs | Back from the sequencing centre; Read QC; Read-to-reference alignment; Variant calling |
| **Day 2** | From SNPs to insights | SNP filtering; Exploring your dataset; Downstream analyses |

## How to use this manual

Work through the sidebar top to bottom. Start with the **Overview** section to set up
your environment, then follow Day 1 and Day 2 in order. Each page opens with its learning
objectives, walks through the commands, and (for the session pages) ends with an exercise.
Code blocks have a copy button in the top-right corner.

!!! info "About this course"
    - **Format:** 2 days, hands-on, ~40% theory / 60% practical.
    - **Approach:** the most compute-intensive steps (mapping, variant calling) are partly pre-computed so we can focus on understanding each stage.
    - **You will need:** basic command-line comfort. See [Shell navigation](overview/shell-navigation.md) and [Software](overview/software.md) before Day 1.
