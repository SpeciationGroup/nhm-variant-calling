    Genome scans: Estimating genetic differentiation (Fst), diversity (π), and divergence (dxy) in sliding windows¶

    Learning objectives

    By the end of this session you will:

    • Be able to extract a specific region of a VCF file
    • Be able to convert into .geno format
    • Be able to execute windowed analyses of π, \(d_{xy}\), and \(F_{ST}\)
    • Hone your skills at interpreting documentation and help messages
    • Be in a good position to interpret basic genome scans

    1. The dataset¶

    In this exercise we will work with a dataset that compares patterns of genome-wide variation between egg-laying and live-bearing populations from the genus Littorina. The dataset consists of 108 individuals, of which 28 are egg-laying and the remaining 80 are live-bearing.

    One useful feature of this VCF file is that it includes calls for both variant and invariant sites in the genome. This is important for the correct calculation of nucleotide diversity (π) and divergence \((d_{xy})\), which measure the proportion of nucleotide sites that differ between pairs of sequences. If we included only SNPs, invariant positions would be absent from the denominator and estimates of π and \(d_{xy}\) would therefore be greatly inflated.

    The data are also phased. Diploid individuals carry two chromosome copies, and at heterozygous sites we may know which two alleles an individual carries without knowing which alleles occur together on the same chromosome. Phasing attempts to infer this arrangement, allowing the two haplotypes carried by each individual to be reconstructed across the genome. In other words, it tells us which alleles at different SNPs are likely to have been inherited together on the same chromosome copy. Phasing of this dataset was performed using Beagle 2.

    2. Converting the dataset into .geno format¶

    The software we will use to compute our windowed statistics was written by Simon Martin during his postdoctoral work at Cambridge, where he studied Heliconius. Simon is now a group leader at the University of Edinburgh, and he maintains an increadible GitHub repository called Genomics_General:

    https://github.com/simonhmartin/genomics_general

    This has become a one-stop shop for many people who analyse population genomic data, not only because Simon's work is brilliant, but also because his documentation is so clear and the output of the results is so easy to work with. He also maintains several other useful repos which are worth exploring.

    https://github.com/simonhmartin

    The first step for us will be to git clone the Genomics_general repo into our genome_scan directory

    git clone https://github.com/simonhmartin/genomics_general.git
    Then lets move the vcf file that we produced into the Genomics_general directory. You can do this using the mv command

    Show the answer 
    ### This example uses full paths for both the target file to move and the target directory to move to
mv  ~/genome_scan/LittorinaContig1808_subset.vcf.gz ~/genome_scan/genomics_general

    Now cd into Genomics_general and ls to confirm it's there.

    Simon's analysis scripts don't directly parse VCF format and instead require us to convert to a format called .geno. This is achieved via the Python script parseVCF.py, which is located in the directory VCF_processing, but we can call this using the following command.

    python VCF_processing/parseVCF.py -i LittorinaContig1808_subset.vcf.gz -o LittorinaContig1808_subset.geno.gz
    If successful, your genomics_general directory will now contain the file LittorinaContig1808_subset.geno.gz which we can now use to calculate our windowed staisitcs.

    3. preparing a population map¶

    The measures that we want to compute either estimate variation within groups (π) or between groups (\(d_{xy}\) and \(F_{ST}\)), so we need to provide more information than just the .geno file. We also need to provide a population map (referred to as the popsFile in genomics_general framework), which is a list of all of the samples in the vcf file, along with the 'population' that they belong to.

    Here I have deliberately put 'population' in inverted commas, because what we really mean by population is just the groupings that we want to make, and these can be anything that makes biological sense.

    The format of the popsFile is: 

    sample_1 popA
sample_2 popA
sample_3 popA
sample_4 popB
sample_5 popB
sample_6 popB
    This is just a text file including the sample names and population IDs separated by whitespace. The above popsFile includes 6 samples associated with two populations (popA & popB)

    In our case, we want to assign invdiuals to either the "Egglayer" or "Brooder" group.

    We have prepared this file, called pops.txt, for you, but you must copy it into your genomics_general directory. It's located here:

    /home/Share/genome_scan/pops.txt

    5. Calculating stats in overlapping windows of a fixed size¶

    As mentioned in the presentation, this kind of analysis can be conducted in overlapping and non-overlapping windows. Windows will always overlap if the step size is smaller than the window size.

    In this analysis, we will use a window size of 3000 bp and a step size of 100 bp, which is similar to the parameters used in the paper where these data were analysed.

    Try and write a script that uses all of these flags: -w -s -g -o -f -T -p --popsFile --windType. Because we are limited in compute resources, your analysis must use 1 thread. Also, be sure to name your output something sensible (I find it useful to include the window size and step size in the name, so I can keep track of different analyses)!

    If you are stuck, its always a good idea to refer to the documentation on the GitHub page!

    Show the answer 
    python popgenWindows.py -g ~/genome_scan/genomics_general/LittorinaContig1808_subset.geno.gz -w 3000 --windType coordinate -s 100 -m 20 -o LittorinaContig1808_windows_w3000_s100.csv -f phased -T 1 -p Egglayer -p Brooder --popsFile pops.txt

    python popgenWindows.py -g ~/genome_scan/genomics_general/LittorinaContig1808_subset.geno.gz \
-o LittorinaContig1808_windows_w3000_s100.csv \

    6. Understanding the output¶

    The output of popgenWindows.py is a .csv file. At this point, the easiest way to work with this is to download it to your own machine and work with it in R or Python. The code that provided below is base R, but use whatever you prefer.

    First load in the data frame called plot_data. The data frame has headers.

    Show the answer 
    plot_data <- read.csv("LittorinaContig1808_windows_w3000_s100.csv", header = TRUE)

    Now, look at the first few lines of the data frame

    Show the answer 
    head(plot_data)

    You will see that our data frame contains 9 columns. Here is what each column represents:

    • scaffold : This is the scaffold or contig of the genome assembly that the window is on. These can be - contigs, scaffolds, or chromosomes.
    • start : The base-pair position for the start of the window.
    • end : The base-pair position for the end of the window.
    • mid : The midpoint of first and the last SNP in the window.
    • sites : The number of sites in the window.
    • pi_group : The estimate of nucleotide diversity (π) in the window for each of the groups analysed.
    • dxy_group1_group2 : The estimate of between-group divergence (\(d_{xy}\)) between each pair of groups.
    • fst_group1_group2 : The estimate of between-group differentiation (\(F_{ST}\)) between each pair of groups.

    7. plotting the results¶

    Now it's time for the fun part. Let's see how diversity, divergence, and differentiation vary across the genome. We will use the midpoint of each window as the position on the x-axis.

    Recall that π and \(d_{xy}\) are actually calculated the same way, except that π is calculated within groups and \(d_{xy}\) is calculated between groups. In most cases, we should be able to plot these on the same plot, as they have the same scale

    \(F_{ST}\) will generally have a much broader span, as it ranges from 0 to 1. Therefore, we will need to plot \(F_{ST}\) separately.

    Plot \(F_{ST}\) first, setting the y-axis limits to span from 0 to 1

    Supplement 1: Information about the calculation of π, \(d_{xy}\) and \(F_{ST}\)¶

    For two sequences, (i) and (j), their genetic distance can be thought of as:

    \[ d_{ij} = \frac{\text{number of sites at which } i \neq j} {\text{number of sites compared}} \]

    Nucleotide diversity (π) is the mean pairwise distance between chromosome copies sampled from the same population:

    \[ \pi = \frac{1}{N_{\text{pairs}}}\sum_{i<j}d_{ij} \]

    Thus, π measures the average proportion of nucleotide sites at which two chromosome copies from the same population differ.

    Absolute divergence \((d_{xy})\) is the mean pairwise distance between chromosome copies sampled from two different populations:

    \[ d_{xy} = \frac{1}{n_xn_y} \sum_{i \in x}\sum_{j \in y} d_{ij} \]

    where (\(n_{x}\)) and (\(n_{y}\)) are the numbers of chromosome copies sampled from populations (\(x\)) and (\(y\)). Unlike π, which measures variation within a population, \(d_{xy}\) measures sequence divergence between populations.

    The \(F_{ST}\) statistic calculated in this exercise compares diversity within populations with diversity in the two populations combined:

    \[ F_{ST} = 1-\frac{\pi_S}{\pi_T} \]

    where \(pi_{S}\) is the average diversity within the two populations, weighted by their sample sizes:

    \[ \pi_S = \frac{n_x}{n_x+n_y}\pi_x+ \frac{n_y}{n_x+n_y}\pi_y \]

    and \(pi_{T}\) is the mean pairwise diversity when chromosome copies from the two populations are pooled. \(F_{ST}\) therefore measures how much genetic variation is partitioned between, rather than within, populations.
